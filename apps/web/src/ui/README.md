# Componentes de interface

Esta pasta concentra os componentes reutilizáveis do design system.

- `Button`: variantes primária, secundária, perigo, ícone e neutra.
- `Card`: superfície elevada de conteúdo.
- `Input` e `Select`: campos com estilo e foco consistentes.
- `Modal`: modal em portal com backdrop de viewport.
- `PageHeader`: título, subtítulo e faixa de filtros padronizados.

Todos os componentes aceitam ou fornecem um `data-testid` estável. As
features devem preferir estes componentes em vez de repetir estilos de
botões, campos, superfícies ou overlays.
